# ACC — Sensors & Socket Connection

Isolated module handling real-time sensor data ingestion and WebSocket communication for the Smart Agriculture Assistant project.

## What It Does

Reads hardware sensor inputs and broadcasts them in real time to connected clients via Socket.io.

## Stack

Node.js, Express, Socket.io

## Setup

```bash
npm install
node app.js
```

> Part of the larger [ACC-final-ver](https://github.com/minh-stakc/ACC-final-ver) project.
